# SIH 2026 Hackathon Demo Walkthrough (5-8 Minutes)

1. Open `http://localhost:3000` and click **SIH Demo Mode**.
2. Click **Proceed to Step 1** to upload synthetic inspection package (`Pump_Inspection_Report.pdf`, `Pump_Sensor_Data.csv`, `Pump_Image.jpg`).
3. Observe Model Router auto-select Reasoning, Vision, and Coding models.
4. Watch OCR, image inspection, and sandboxed Python analytics calculate peak vibration (6.8 mm/s).
5. Review RAG citation (`Pump_Maintenance_SOP.pdf — Page 24`).
6. Click **Approve** on the Human-in-the-Loop review card.
7. Download generated `.docx` Maintenance Approval Note and `.xlsx` Sensor Workbook.
8. Verify Sovereignty Monitor showing 0 MB external egress.
